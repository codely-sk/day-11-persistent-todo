# Day 11 – Persistent To-Do List 📝

## About the Project
The Persistent To-Do List is a Python application that helps users manage daily tasks. Unlike a basic to-do list, this version saves tasks in a JSON file, allowing them to remain available after the program closes.

## Features
- Add new tasks
- View saved tasks
- Mark tasks as completed
- Delete tasks
- Save tasks automatically
- Load previously saved tasks when the program starts
- Handle invalid task numbers and menu choices

## Concepts Used
- Lists and dictionaries
- Functions and loops
- JSON data storage
- File handling using `open()`
- `json.load()` and `json.dump()`
- `os.path.exists()`
- Exception handling using `try-except`

## What I Learned
- How to save data permanently using JSON
- How to read saved data when a program starts
- How to update stored data after an operation
- How to work with files in Python
- How to handle missing or invalid saved data

## How to Run
1. Install Python.
2. Open the project folder in VS Code.
3. Run `day_11_persistent_todo.py`.
4. Add tasks and close the program.
5. Run it again to see your saved tasks.
